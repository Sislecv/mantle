# Mantle: Deltarune Chapter 1 (8-Bit Demake) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a complete, playable 8-bit browser-based demake of Deltarune Chapter 1 styled after Chapter 3's "Mantle" / Sword Route NES minigame, featuring real-time sword slashing & obstacle cutting, party follower dynamics, retro puzzles, typewriter dialogues, and an 8-bit SOUL bullet-box combat system for boss fights.

**Architecture:** A lightweight, modular HTML5 Canvas + TypeScript architecture running at native NES resolution (256×240) scaled with pixel-perfect CRT presentation. Composed of an overworld tilemap/collision engine, Kris state machine (unarmed -> sword pull -> 5-frame attack), typewriter dialogue system with procedural 8-bit Web Audio blips, trailing party queue, and a battle-box bullet-hell state machine for iconic Chapter 1 bosses.

**Tech Stack:** TypeScript, Vite, HTML5 Canvas 2D API, Web Audio API, Vitest for automated testing.

**Spec:** [mantle_ch1_systems_design.md](file:///home/sislecv2/.gemini/antigravity-cli/brain/393ba3e1-fec2-4465-9cd0-747ab2a13189/mantle_ch1_systems_design.md)

## Global Constraints

- Native canvas resolution must be exactly 256×240 pixels (Famicom/NES standard), scaled via CSS with `image-rendering: pixelated`.
- Sprites and tiles must follow 16×16 base grid (characters: 16×16 or 16×24, bosses: 24×32 or 32×32, portraits: 32×32).
- Palettes must adhere to strict 4-color NES rules (1 transparent + 3 colors per entity).
- Sound effects must be generated procedurally via Web Audio API (square wave, triangle wave, noise) to eliminate missing audio asset errors and ensure authentic chiptune audio.
- Zero external runtime heavy game engine dependencies (pure Canvas 2D + TypeScript).
- All tests must pass with Vitest.
